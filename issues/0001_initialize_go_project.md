## Суть задачи

Подготовить репозиторий `localcloud` к разработке: заложить основу
консольного приложения на Go, которое пользователь может установить одной
командой из репозитория — без ручной сборки, дополнительных зависимостей и
специальной настройки окружения.

Каркас должен сразу давать базовый пользовательский опыт: подсказку по
использованию, информацию о том, какая версия установлена, и понятные
сообщения при неверном вводе. Структура проекта должна позволять добавлять
новые команды без разрастания одного файла, а установка из репозитория должна
оставаться простой и предсказуемой.

## Критерии готовности

- [x] Имя пакета совпадает с адресом репозитория в git.
- [x] Проект устанавливается одной командой `go install github.com/alzasr/localcloud@latest`.
- [x] После установки доступна команда `localcloud`.
- [x] `localcloud help` (`-h`, `--help`) объясняет, какие команды доступны.
- [x] `localcloud version` (`-v`, `--version`) показывает версию, коммит и дату сборки.
- [x] Неизвестная команда не приводит к падению: выводится понятное сообщение и ненулевой код возврата.
- [x] Команды отделены от точки входа и покрыты автотестами.
- [x] README объясняет установку, сборку из исходников и запуск.
