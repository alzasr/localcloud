# Черновики задач

Каталог для набросков будущих задач. Черновики живут в ветке `drafts` и в
основную ветку не попадают: оформленная задача переносится в `issues/` как
`NNNN_short_task_name.md`, а черновик удаляется.

- Имя файла: `short_task_name.md` — английский snake_case без номера.
- Содержание: заголовок `# English task name` и раздел «Суть задачи» — что и
  зачем нужно сделать. Критерии готовности появляются при оформлении задачи.

Правила ведения задач: [../README.md](../README.md).
